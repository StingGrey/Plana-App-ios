# Plana App · 设计需求说明书 v2(致设计侧)

> 你(设计侧)将为一个 **AI 动漫插画生成 App** 设计移动端 UI。本文档 v2 的主体是 **§5 逐功能交互规格**——全部来自一个已上线、被高强度使用的移动端网页版的实战设计,每条都写明"用户做什么 → 界面发生什么",并标注设计动机(键盘、单手、误触等真实约束)。
>
> **规则:凡标注〔硬约束〕的流程与信息完整性不可改;视觉表现、布局组织、动效风格、交互机制由你发挥。** 拿不准就问,不要自行想象流程。
>
> **特别注意:参考版是"网页",它的交互机制被浏览器束缚过**(长按会触发文本选择、横滑与浏览器前进后退冲突、无触感反馈……),所以它大量用按钮替代手势。本 App 是原生应用,没有这些束缚——**§3.3 逐条列出了应当超越参考版的地方,请主动利用原生能力做得更好**。判断法:一个参考版设计是"为了解决用户问题"(继承)还是"为了绕开浏览器"(超越)。
>
> 分批设计,批次划分见 §7。

## 1. 产品与用户(30 秒版)

- **Plana** = NovelAI(付费 AI 动漫插画服务,下称 NAI)的第三方 Android 原生客户端。官方无 App。
- 用户:已付费的 AI 绘画爱好者(多为最高档 Opus 订阅),熟悉英文标签(Danbooru 体系)写提示词,一条提示词 30~100+ 个标签,反复微调是常态。
- 核心循环:**写/改提示词 → 生成(10~30 秒)→ 看图 → 再改 → 再生成**,一次创作会循环几十遍。一切设计为这个循环的流畅度服务。
- 单人创作工具,非社区。无 feed、无点赞。
- 竖屏、暗色唯一、简体中文界面(提示词内容是英文)。

## 3. 全局骨架

### 3.1 导航

底部 3 tab:**创作 / 图库 / 我的**。(参考版是 4 tab,含独立"工具"页;本 App 把工具收进"我的",导航更简。)

〔硬约束〕以下全局行为:

1. **全屏编辑器打开时,底部导航栏整体隐藏**(编辑器需要每一像素,见 §5.1)。
2. **自动切页规则**:点「生成」→ 自动切到图库 tab 展示进度与结果;从图库/工具做「参数导入」→ 自动切回创作 tab。
3. **Android 返回键分层关闭**,优先级:全屏查看器 > 各类弹窗/Sheet > 全屏编辑器(等同保存返回)> 回退上一个 tab > 回到创作 tab > 退出 App。每一层返回键只关最上层,绝不跳级。

### 3.2 移动端工程约束(设计必须知道的物理现实)

- **键盘占掉下半屏**:任何"输入 + 实时候选"的场景,可用高度只剩 ~40%。这就是提示词必须用**独立全屏编辑页**而不是页内输入框的原因。
- **键盘避让**:全屏编辑器高度跟随键盘 inset 动态变化,补全条永远吸在键盘正上方。
- **安全区**:吸底元素(导航、生成栏、Sheet)下方预留手势条安全区。
- **触控反馈**:可点元素按压有视觉反馈;关键节点接入系统触感(haptics):拖拽拿起/落位、进入多选、生成完成、错误。44dp 最小触控目标。(参考版的 `navigator.vibrate` 兼容性差近乎无触感,App 端触感是标配。)
- **横滚容器**:补全条、缩略图条、chips 行均为隐藏滚动条的横向滚动。

### 3.3 原生能力红利:参考版受限设计 → App 应升级〔请主动采用〕

| 参考版的做法(受限原因) | App 应升级为 |
|---|---|
| tab 只能点按切换(横滑与浏览器历史手势冲突) | 可滑动切 tab;注意与页内横滚区做手势仲裁,冲突区域宁可禁用 |
| 拖拽排序 = 长按 300ms + 自绘半透明浮层(HTML 拖拽在移动浏览器不可用) | 原生拖拽:即拿即走、跟手、投影与落位动画、触感 |
| 删除标签芯片要先选中再点按钮(不敢用滑动手势) | 芯片左滑删除 / 长按弹上下文菜单(权重/禁用/删除);面板按钮保留兜底 |
| 查看器切图只能点底部缩略图 | 全屏内**左右滑切图** + **下滑关闭**(跟手回弹);缩略条联动 |
| 多选模式靠工具栏开关按钮进入 | **长按缩略图直接进入多选**(原生标准手势);按钮入口保留 |
| Sheet 只能点 X 或遮罩关闭 | 顶部拖拽把手、下滑关闭、半屏↔全屏 snap 点 |
| 返回键靠 history hack,无动画 | 原生返回栈 + Android 预测性返回动画(分层关闭逻辑不变,见 §3.1) |
| 生成中切走页面可能被浏览器冻结/杀掉 | **后台继续生成,完成发系统通知**(设置可关),回 App 直达结果 |
| 双击/捏合与浏览器页面缩放冲突,手势保守 | 查看器手势全接管:缩放/平移/双击/滑动毫无顾忌 |
| 长按会触发浏览器文本选择/图片菜单,能不用就不用 | 长按是一等公民:预览、菜单、多选、拖拽随需使用 |
| 长列表性能受限 | 原生懒加载,图库千张不卡 |

两条使用原则:
1. **手势可发现性**:纯手势操作(左滑删除、长按多选)必须有可见替代入口或首次轻引导——手势是加速器,不是唯一路径。
2. **手势仲裁**:嵌套滚动/滑动的冲突(tab 横滑 vs 补全条横滚)必须显式设计,不能两个都要。

## 4. 领域概念词典(带精确规则)

| 概念 | 规则 | 设计含义 |
|---|---|---|
| 提示词 | 英文逗号分隔标签;**总长上限 512 token**(T5 分词,App 内实时计数) | 编辑器顶部要有 token 进度条,超限变红 |
| 权重语法 | `{tag}` 加权(可叠层)、`[tag]` 降权、`1.5::tag::` 数值权重、`~tag` 临时禁用 | 编辑器内必须可视化(见 §5.1),不能让用户手打括号 |
| 负面提示词 | 结构同上,有默认模板,低频修改 | 主页折叠;编辑体验与正面完全一致,红色主题 |
| 模型 | 5 选 1:NAI 4.5 Full / 4.5 Curated / 4.0 Full / 4.0 Curated / V3 | 顶栏下拉,显示当前值 |
| 分辨率 | 三组预设:小图(832×1216 竖/1216×832 横/1024×1024 方,Opus 免费档)、大图、壁纸;每档显示比例+像素 | 选择 Sheet 用 3 个 tab 分组,卡片带比例预览框 |
| 多角色 | 每角色独立正/负提示词 + 可选位置(5×5 网格,列 A-E 行 1-5)或 AUTO;上限 **6** 个;可单独禁用某个角色 | 见 §5.3 |
| 生成参数 | 步数 1-50(默认 28)、引导 CFG 0-25 步进 0.1(默认 5)+ Variety+ 开关、采样器 6 选 1、seed(空=随机)、CFG Rescale 0-1、噪声调度 | 全部收进「高级设置」Sheet |
| Anlas | NAI 点数。Opus 用户:小图档+≤28 步+单张 = **免费**;否则按张扣点 | 顶栏常驻余额(点击刷新);生成按钮上实时显示本次费用/「免费」 |
| Token 登录 | 用户从 NAI 官网复制 `pst-` 开头的持久令牌 | 输入框校验前缀,不合法即时红字;密文显示可切换 |
| 生成过程 | 10~30 秒;可流式返回中间预览图(逐步清晰);失败原因:网络/服务异常/内容审核/点数不足 | 进度 = 步数 X/Y + 中间预览;失败分原因给文案与动作 |
| 图片元数据 | 每张 PNG 内嵌全部生成参数(prompt/negative/角色/seed/steps/...) | 任何看图处都可「导入参数」一键回填创作页;下载时可选保留/清除元数据 |

## 5. 逐功能交互规格

### 5.1 提示词编辑器(整个 App 最重要的界面)〔硬约束〕

**为什么是独立全屏页**:输入时键盘占一半,剩余空间还要同时容纳「已输入的几十个标签」和「实时补全候选」。页内小输入框做不到,参考版验证了全屏编辑页是正确解法。

**入口**:创作页的提示词卡片(显示摘要,最多 3 行,带 token 计数)整卡可点 → 推入全屏编辑器。正面/负面/每个角色的正负面,共用同一个编辑器组件,只换主题色(正面金/负面红)和数据。

**编辑器布局(上→下)**:
1. **顶栏(固定)**:返回按钮(=保存并退出,无单独保存键)· token 进度条(x/512,超限红)· 撤销按钮(无历史时置灰)· 芯片/纯文本模式切换。
2. **芯片流区(滚动,占剩余空间)**:已输入标签渲染为**芯片**,flex 流式换行;行内末尾跟一个**透明输入框**(占位符:无标签时"输入标签,逗号分隔…",有标签后"继续添加…")。
3. **补全条(吸在键盘上方,固定高度)**:见下。

**芯片规格**:
- 两行内容:上行=标签名(下划线显示为空格),下行=中文翻译或权重值。
- 权重可视化:`{}` 橙色背景、`[]` 蓝色背景、数值权重显示数字、`~` 禁用=删除线+50% 透明、异常权重(嵌套过深等)=红底+警告图标。
- **点击芯片** → 选中,底部弹出**权重面板**(替换补全条位置):
  - 行 1:已选数量或该标签中文翻译;
  - 行 2:`{+}` 加权、`[−]` 降权、数值微调(− 值 +,步进 0.1);
  - 行 3:权重预设快捷键(如 0.5 / 0.8 / 1.5 / 2.0);
  - 行 4:清除权重 · 禁用/启用(~切换)· 删除 · (单选时)编辑文本。
- **多选**:选中后继续点其他芯片累加选中,权重面板变为批量操作。
- **拖拽排序**:长按芯片即拿起(原生拖拽:跟手、投影、落位动画、触感),目标位置显示占位,靠近容器上下边缘自动滚动。(参考版的"300ms 长按 + 自绘浮层"是浏览器妥协,不要照搬其生硬手感。)
- **快捷删除(原生红利)**:芯片左滑露出删除;或长按弹上下文菜单(调权重/禁用/删除)。权重面板内的删除按钮保留兜底。
- **输入框行为**:输入逗号(中英文均可)即把前面文本提交为芯片;Backspace 在空输入时删除最后一个芯片;粘贴长文本自动按逗号拆成多个芯片。

**纯文本模式**:一个全屏 textarea,给习惯手写权重语法的重度用户;补全仍然工作(替换光标所在词)。模式切换按钮在顶栏。

**补全条**〔硬约束〕:
- 位置:永远吸在键盘正上方,不遮挡芯片流。
- 结构:最多三行,每行独立横滚:① 画师串候选(v2 才有,v1 隐藏)② 角色词库候选 ③ 普通标签候选。
- 触发:英文 ≥2 字符、中文 ≥1 字符,防抖 250ms,中文输入法组词中不触发(选字上屏后才查)。
- 候选项内容:上行=英文标签 + 热度(如 `12k`,≥1000 才显示);下行=中文翻译或分类;分类用小图标区分(角色/画师/普通/AI)。
- 选中行为:替换当前正在输入的词 → 自动补 `, ` → 光标就位可继续输入,补全条刷新。
- **中文搜索**:输入中文能搜到对应英文标签(词库含中文翻译与别名)。
- v1 数据源:App 内置标签词库(含中文翻译)+ Danbooru 公开补全接口;AI 推荐与语义搜索是 v2(设计上给第三行留位即可)。

### 5.2 创作页(主屏)

**布局(上→下)**:
1. **顶栏(固定)**:模型下拉(左)· Anlas 余额按钮(右,金色数字,点击刷新,加载时转圈)。
2. **滚动主体**:
   - **提示词卡**:正面摘要区(可点进编辑器)+ 分隔 + 负面摘要区(红色主题,可点)。每区右上角:token 计数 + 清空按钮。
   - **辅助工具行**:4 个等宽小按钮位(参考版为 AI 助手/画师串/灵感/OC——全部依赖服务器,**v1 全部隐藏**,但布局预留这一行)。
   - **角色面板**(折叠卡,见 §5.3)。
   - **(v1.5+ 预留)Vibe 面板 / 精准参考面板 / 图生图面板**:同样式折叠卡,v1 不出现。设计上确认"折叠卡堆叠"的视觉节奏即可。
3. **吸底生成栏(固定,含安全区)**:高级设置按钮(滑块图标)· 分辨率按钮(显示当前档如 `832×1216`)· 参数导入按钮 · **生成按钮(flex-1,金色)**。

**生成按钮状态机**〔硬约束〕:
| 状态 | 展示 | 可交互 |
|---|---|---|
| 正常 | 金底黑字「生成」+ 费用徽章(「免费」绿 /「≈N Anlas」) | 点击开始 |
| 生成中 | 灰底 + 转圈 +「生成中 X/Y」步数,按钮背景内嵌进度条按步数推进 | 不可再点(防双击),不可取消 |
| 完成 | 回到正常态 | — |
| 失败 | 回到正常态 + 按钮上方错误条(分:网络超时/NAI 服务异常/内容被拒/Anlas 不足→附「调低配置」引导) | 可重试 |

点生成后**自动切到图库 tab**,大图区显示流式中间预览(逐步清晰)+ 步数进度;用户可随时切回创作页继续改词(不打断生成)。〔原生红利〕生成期间切到别的 App:任务后台继续,完成时发系统通知(设置可关),点通知直达结果——参考版"切走就可能被浏览器杀掉"的顾虑不复存在。

**分辨率 Sheet**:底部弹出,3 个 tab(小图/大图/壁纸),3 列网格卡片(比例预览框 + 比例文字 + 像素值),大图/壁纸档标注 Anlas 消耗;**选中不即时关闭,底部确认按钮生效**(防误触)。

**高级设置 Sheet**:底部弹出(max 80% 高,内滚):步数滑杆 · CFG 滑杆 + Variety+ 开关 · 采样器按钮组(2 列)· seed 输入框(带清空;空=随机)· CFG Rescale 滑杆 · 噪声调度按钮组 · **提示词预设折叠区**(选一个预设自动并入正/负提示词)。底部固定:「恢复默认」+「确认」。

全部 Sheet 通用〔原生红利〕:顶部拖拽把手、下滑关闭、需要更多空间的 Sheet 支持半屏↔全屏 snap。

### 5.3 多角色面板〔硬约束,本产品差异化功能〕

- **面板头**:标题「角色」+ 绿色计数角标 + 展开/折叠箭头 + 清空 + 添加按钮(≥6 个时置灰)。
- **每个角色一行**,行内从左到右:
  - **启用开关**(电源图标:开=绿,关=灰。禁用的角色不参与生成但保留配置——用户靠这个做 AB 对比);
  - 角色名(自动"角色 1/2/…"或自定义);
  - **正/负切换小 tab**(✨金 / ⛔红,决定下方编辑区显示哪份内容);
  - 上移/下移/删除按钮。
- 行下方:**内容摘要区**(点击 → 进 §5.1 全屏编辑器编辑该角色当前 tab 的内容)+ **位置按钮**(网格图标 + 当前值 `A1`~`E5` 或 `AUTO`)+ token 计数。
- **位置选择弹窗**:居中 modal,5×5 网格,列标 A-E、行标 1-5;**格内显示已占用角色的序号圆点**(多角色同格可见);点格选中(高亮),底部「AUTO」按钮 = 交给 AI 摆位;确认生效。

### 5.4 图库 tab(结果 + 历史一体)

**布局**:
1. **主区(大图)**:当前选中图等比居中;生成中显示流式预览 + 步数;支持双指捏合进全屏、单击进全屏。
2. **主区右下悬浮操作组**:Seed 按钮(显示种子号,点击=把种子填回创作页)· 重新生成(用当前图参数再来一张)· 下载 · 参数导入(整套参数回填创作页)。
3. **底部缩略图条(横滚)**:历史缩略图 + 生成中占位;当前图金色描边;缩略图角标:`4x/2x`(超分,绿)、`重绘`(蓝);左下角显示 seed。
4. **展开按钮** → **全量网格视图**(3 列):
   - 普通态:单张右下下载/删除;
   - **多选态**(〔原生红利〕**长按任意缩略图直接进入**;顶部勾选图标保留为可见入口):每张左上勾选框,底部工具栏变「全选/取消全选 · 打包下载(ZIP)· 删除」。

**全屏查看器**〔硬约束手势〕:
