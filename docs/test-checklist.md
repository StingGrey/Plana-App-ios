# Plana App · 发布前必测清单

> **32 条。** 这不是「功能覆盖清单」,是「beta 用户替不了你测的那部分」。
>
> 筛选标准只有一条:**撞上了会不可逆,或者撞不上 beta 就无从开始**。
> 具体是三类 —— ⓐ 花钱(扣了退不回)· ⓑ 数据(丢了找不回)· ⓒ 冒烟(不通则 beta 无意义)。
>
> 外观、文案、边缘交互、低频页面(法典/统计/工具/灵感)**全部下放给 beta 用户** ——
> 那些他们撞得比你多,而且报出来你随时能改。
>
> 失败回报格式:`编号 + 现象 + 一句复现`。例:`B-05 队列断网后自己重跑了一张`。

---

## ⓐ 花钱安全(9)

扣错的点退不回来,beta 用户也说不清"我是不是被多扣了"。这九条必须在发布前闭环。

- [ ] **A-01** 免费档参数(Opus·≤28步·≤1024²)→ 生成按钮显示「免费」;调大尺寸或步数 → 变 `≈N Anlas`
- [ ] **A-02** **快速连点生成按钮 → 只出一张图**。生成前后记一下点数,确认只扣了一次 〔验 S2-01〕
- [ ] **A-03** ∞ 循环 + **收费**参数 → 开跑前弹确认弹窗,写明每张点数
- [ ] **A-04** ∞ 循环 + **免费**参数 → 不弹,直接跑;有限张数 + 收费 → 也不弹 〔验 S1B-05〕
- [ ] **A-05** 队列跑到一半拔网 → 失败任务放回队首、队列暂停,**不自己重跑**;恢复网络后手动继续 〔验 S1B-01〕
- [ ] **A-06** 同一张 Vibe 参考图、同模型同 IE,第二次生成 → **不再扣 2 点编码费**(对比前后点数)〔验 S1B-04〕
- [ ] **A-07** NAI 官方 4× 超分 → 实扣 **7 点**,与方式面板写的「7 点」一致 〔验 S1B-06〕
- [ ] **A-08** 生成中点停止 → 立即回空闲态、无错误弹窗;点数没有继续变化
- [ ] **A-09** 顶栏点数在生成/超分后自动刷新,数字与实际相符

## ⓑ 数据安全(10)

丢了找不回。beta 用户丢一次就不会再用了。

- [ ] **B-01** 编辑器改完词 → **1 秒内立刻杀进程** → 重启,改动还在 〔验 S1C-02〕
- [ ] **B-02** 加了 Vibe / 角色参考 / 图生图后杀进程 → 重启,图和参数都回来
- [ ] **B-03** 图库历史图杀进程重启后全在,能翻能看
- [ ] **B-04** 「清空图库」后再生成 → 新图不覆盖任何东西,文件名不复用旧编号 〔验 S1C-01〕
- [ ] **B-05** 用 `~` 禁用几个词 → 杀进程重启 → 词还在且仍是禁用态
- [ ] **B-06** 主题色、生成默认参数、保存设置 —— 改过的值重启后都在 〔验 S1C-11〕
- [ ] **B-07** 登录态(令牌 / Bot 会话)重启后仍有效,不用重新登录
- [ ] **B-08** 本地超分「质量」档**首次**使用(要解压 8.5MB 模型)→ 成功出图;若中途杀进程,再进来仍能正常超分 〔验 今日修复〕
- [ ] **B-09** 删除单张 / 批量删除 → 只删掉选中的,其余不受影响
- [ ] **B-10** 图库到达上限后自动裁最旧的,文件同步删除,不留孤儿

## ⓒ 冒烟:核心链路(13)

这些不通,beta 根本开不起来。每条只求"走得通",不挑细节。

## 主动下放给 beta 的部分

不是没测,是**判断由 beta 用户测更划算**。列在这里以免以后误以为漏了:

| 下放内容 | 理由 |
|---|---|
| 全部外观与文案细节 | 主观、易改、不可逆风险为零 |
| 手势细节(拖拽手感、滑动仲裁、预测性返回动画) | 依赖机型与个人习惯,单机验证代表性差 |
| 低频页面:灵感 / 法典 / 统计 / 工具 / 公共库 | 用得少、坏了不影响主循环,且多为只读 |
| 各类边界态文案(空态引导语、错误措辞) | beta 撞得比你多 |
| 参数面板逐项(分辨率各档、采样器、噪声调度…) | 参数只影响出图效果,不影响正确性 |
| 多角色位置网格、角色 AB 对比等进阶用法 | 高级功能,重度用户会主动反馈 |

**若 beta 期间收到反馈,按原 320 条清单的分区归位即可** —— 那份清单的分区结构仍然有效,只是不再由你一个人跑完。
